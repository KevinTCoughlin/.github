# Support

This is the default support guide for every repository in the `KevinTCoughlin` account that
doesn't have its own `SUPPORT.md`.

## Where to ask

Ask questions in the affected repository's **Discussions** tab. If Discussions is turned off
there, open a blank issue instead.

Security problems are not support requests. Report those privately, as
[SECURITY.md](SECURITY.md) describes.

## What to expect

Responses are best effort. There is no guaranteed reply time. Fixes and releases come first.
